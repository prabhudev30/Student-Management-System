# Student Management System

## 📌 Project Overview

Student Management System is a C-based console application used to manage student records. It allows users to add student details and view stored records using file handling.

## 🚀 Features

- Add student details
- View student records
- Store data permanently using file handling
- Menu-driven console interface

## 🛠️ Technologies Used

- C Programming
- Structures
- File Handling
- Functions
